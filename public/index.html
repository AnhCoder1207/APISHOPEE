Tài khoản Shopee Affiliate

Xuất cookie bằng J2TEAM Cookies rồi tải file JSON lên; CamLink tự lọc và mã hóa trước khi lưu.

J2

Cách lấy cookie an toàn

  1. Đăng nhập tại affiliate.shopee.vn.
  2. Mở extension J2TEAM Cookies và xuất cookies thành file JSON.
  3. Vào CamLink, bấm “Thêm tài khoản Shopee” rồi chọn file vừa tải.
  4. CamLink chỉ giữ header cookie đã mã hóa; file JSON không được lưu lại.

Cookie là thông tin đăng nhập. Không gửi file cho người khác và hãy xóa file khỏi thư mục Downloads sau khi import.

API key cho hệ thống riêng

Mỗi key chỉ hiển thị đầy đủ một lần và có thể thu hồi ngay lập tức.

Key đang hoạt động

Không lưu API key ở frontend hoặc repository công khai.

Gọi API đổi link

Sử dụng tài khoản Shopee mặc định nếu bỏ qua connectionId.

curl -X POST https://your-domain/api/v1/affiliate/convert-link \
  -H "Authorization: Bearer clk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "originalLinks": ["https://shopee.vn/product/..."],
    "subId1": "facebook_reels"
  }'

Endpoint báo cáo: POST /api/v1/affiliate/conversion-reports
